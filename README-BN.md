# HASIB MART BD — Reference Design
This is a fresh React + Vite project styled to follow the screenshots supplied in the conversation:
- dark charcoal/black background with yellow-gold accents
- Hind Siliguri font
- header, search, category navigation, hero banner, service strip, category tiles, product cards, hot deals strip
- Why Choose Us and customer review sections
- responsive layout and WhatsApp order link
- cart is client-side demo only; review form is not stored on a server

## Run locally
1. Install Node.js
2. Open this folder in a terminal
3. Run `npm install`
4. Run `npm run dev`

## Deploy
Upload the contents of this folder (including `src/` and `package.json`) to the root of a new GitHub repository, then import it into Vercel. Vercel settings: Framework Preset `Vite`, Build Command `npm run build`, Output Directory `dist`, Root Directory blank.

## Notes
Sample product data and stock photos are demo content. Replace them with the actual product names, prices, and photos. WhatsApp order link is configured for 8801304627162. This project does not include a database or online payment integration.
